# 送审前审阅

在技能目录运行。仅需 Python 3.9+；不联网、不调用模型、不改写稿件。

```bash
python3 scripts/review_drafts.py 原稿.docx 改稿.docx --org 示例银行 --org 示例支行
python3 scripts/review_drafts.py 单稿.docx
```

支持 `.docx` 正文及 UTF-8 纯文本，输出 Markdown；加 `--json` 输出结构化结果。可重复指定 `--org`；不提供词表就跳过机构名称专项检查。`.docx` 的行号指从 1 开始的 Word 正文直属段落序号（包含空段），不是页码或版面行号；列号按提取文本计算，制表符和段内换行计作一个空格。JSON 的 `docx_inputs` 标明哪些输入使用该定位方式。

## 核对提示

- 金额、比例、日期与阿拉伯数字计数：识别常见人民币单位、完整日期、`件`、`人`、`人次`、`家`、`场次` 等单位和 `约`、`余` 等限定。等值金额换单位、同一天换日期写法不算变更。
- 机构名称、责任主体与政策引用：按词表和常见句式提取。遇到新增、删去或变动的政策引用，人工查对原文、条款与适用性；笼统依据用语及已有的 `［待核实］` 也会单列。
- 案件阶段：提示发现线索、移送、立案、审查调查、处分、行政处罚、起诉、判决等用语。保留规则匹配到的 `拟`、`未`、`尚未` 等限定；移送和立案连在一起时，分别核对，不能据匹配结果认定已经立案。不能确认不同段落说的是同一案件、判决是否生效或哪些信息可披露。

正文表格、页眉页脚、批注、脚注和文本框不在范围内；带有未处理正文修订的 Word 文件不会混读新旧文字，可用副本处理修订后再比对。重排、拆并段落、中文数字、计量对象或统计口径改变及非规则句式可能漏检或带来额外提示。无提示不代表可直接送审，文稿排版仍须单独核验。清单摘录原文，应按稿件的保密要求处理。仓库例稿为虚构材料。
